Доп. параметры клиента для Inbound'ов

Здесь можно настроить параметры, которые будут автоматически добавляться к ссылкам (например, для xhttp обфускации) в подписке пользователей.
Например: extra={"obfs":"123"} или любые другие URL-параметры.

Вид подписки в приложении

Вы можете задать шаблон для названия и описания (фейковая нода сверху).
Переменные: {spent}, {remaining}, {total}, {days_left}, {expire_date}.

Автообновление подписки

Интервал (в часах), через который клиент должен обновлять подписку. Переопределяет значение из Marzban (текущее: 12 ч). Оставьте пустым — будет использоваться значение Marzban.

часов (1–168)
Telegram-бот мониторинга

Бот читает статусы нод из Marzban и постит обновления в канал. Тихие часы настраиваются в настройках каждой ноды.

Оставьте пустым, чтобы не менять текущее значение.
AI-ассистент поддержки

Пользователи пишут боту в ЛС — бот отвечает через OpenRouter API. Нужен ключ с openrouter.ai.
